    **Win32 (comdlg32.dll):**
    ```csharp
    [DllImport("comdlg32.dll", CharSet = CharSet.Unicode)]

    [DllImport("comdlg32.dll", CharSet = CharSet.Unicode)]
    private static extern bool GetSaveFileName(ref OPENFILENAME ofn);
    ```
    - Build OPENFILENAME struct with filter, initial directory, filename buffer
    - Check return value: false means cancelled -> return null
    - true means selected -> extract filename from lpstrFile
    - Handle MULTI style for multiple file selection (null-separated list)

    **macOS (Cocoa):**
    ```csharp
    // Use NSOpenPanel / NSSavePanel via Objective-C runtime
    IntPtr panel = objc_msgSend(NSOpenPanel, sel_openPanel);
    // Configure: setAllowedFileTypes, setDirectoryURL, setAllowsMultipleSelection
    int result = objc_msgSend(panel, sel_runModal);
    // NSModalResponseOK = 1, NSModalResponseCancel = 0
    if (result != 1) return null;
    // Get URL(s) from panel
    ```

    **Linux (GTK):**
    ```csharp
    IntPtr dialog = gtk_file_chooser_dialog_new(
        title, parent,
        GTK_FILE_CHOOSER_ACTION_OPEN, // or _SAVE
        "_Cancel", GTK_RESPONSE_CANCEL,
        "_Open", GTK_RESPONSE_ACCEPT,
        IntPtr.Zero);
    int response = gtk_dialog_run(dialog);
    if (response != GTK_RESPONSE_ACCEPT) {
        gtk_widget_destroy(dialog);
        return null;
    }
    string filename = gtk_file_chooser_get_filename(dialog);
    gtk_widget_destroy(dialog);
    return filename;
    ```

    **DirectoryDialog:** Similar but folder selection mode:
    - Win32: SHBrowseForFolder or IFileOpenDialog with FOS_PICKFOLDERS
    - macOS: NSOpenPanel with setCanChooseDirectories:YES, setCanChooseFiles:NO
    - Linux: GTK_FILE_CHOOSER_ACTION_SELECT_FOLDER
